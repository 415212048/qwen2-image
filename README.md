## Project Introduction

[Qwen2](https://github.com/QwenLM/Qwen3) is a series of large language models independently developed by the Qwen team. This product is based on the Huawei Cloud EulerOS 2.0 64-bit system with the Arm architecture, providing out-of-the-box services.

## Main Applicable Scenarios

- **Natural Language Processing**: Capable of understanding and generating natural language text, suitable for tasks such as conversation, translation, and summarization.
- **Text Generation**: Able to generate coherent and logically clear text, suitable for content creation, story writing, etc.
- **Question Answering System**: Can answer questions raised by users, applicable to scenarios such as customer service and knowledge base queries.
- **Sentiment Analysis**: Can analyze the emotional tendency in text, suitable for market research, public opinion monitoring, etc.
- **Text Classification**: Capable of classifying text, suitable for spam email filtering, news classification, etc.
- **Information Extraction**: Can extract key information from text, suitable for data mining, knowledge graph construction, etc.

The open-source image product [**Qwen2.5-Instruct Model**](https://marketplace.huaweicloud.com/hidden/contents/cdc754e6-2d2c-4bc0-a3ce-814a70949f90#productid=OFFI1121281855531945984) provided by this project has Qwen2-7B-Instruct pre-installed and provides deployment templates. Come and refer to the usage guide to easily start an efficient "out-of-the-box" experience!

> **System requirements are as follows:**
> - CPU: 4 vCPUs or higher
> - RAM: 16 GB or larger
> - Disk: At least 40 GB
